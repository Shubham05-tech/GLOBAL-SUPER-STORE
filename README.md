# 🌎 Global Super Store Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Global Super Store Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides insights into customers, orders, revenue, profit, discounts, products, countries, cities, and sales categories.

## 🎯 Objectives

- Analyze overall sales and revenue performance.
- Understand customer and order trends.
- Analyze profit and profit percentage.
- Compare sales across countries and cities.
- Analyze sales by product category.
- Identify discount patterns.
- Compare revenue and profit across different years.
- Provide an interactive view of business performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

## 📌 Dashboard Features

### Key Performance Indicators

- 👥 Total Customers
- 👤 Unique Customers
- 🛒 Total Orders
- 📦 Unique Orders
- 💰 Total Revenue
- 🏷️ Total Products
- 📉 Maximum Discount
- 📈 Total Profit
- 📊 Profit Percentage
- 💵 Profit per Order
- 🌎 Profit per City
- 🌍 Profit per Country

## 📊 Visualizations

The dashboard includes:

- Country and City analysis
- Revenue and Profit by Year
- Maximum and Minimum Discount by Product
- Sales by Product Category
- Customer-wise analysis
- City-wise Revenue
- Country-wise Revenue and Profit
- Order and customer details
- Interactive filters for analysis

1. Download or clone this repository.
2. Install **Microsoft Power BI Desktop**.
3. Open `Global Super Store.pbix`.
4. Explore the dashboard using the available filters and visualizations.

- The dashboard provides a detailed overview of customer and order activity.
- Revenue and profit can be compared across different years.
- Country and city-level analysis helps identify sales distribution.
- Product-category analysis provides insights into product performance.
- Discount analysis helps understand pricing patterns.
